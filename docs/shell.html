Shell

Interactive shell

Use Onyx like a normal shell target, then reconnect to the same session when the link drops.

Overview Install Shell Exec

Connect

Start a shell session on a remote host.

Shell
onyx user@host

Session behavior

Short drops reconnect automatically. The shell keeps running on the server, and on reconnect Onyx replays exactly the output you missed. No tmux is needed on the remote.

Reconnect

Transport loss triggers reconnect instead of a fresh login. The client retries for up to 30 minutes; status shows in the terminal title.

Catch-up

Missed output is replayed from a 2 MiB buffer per session. After a longer gap, the screen is repainted once.

Native scrollback

A plain login shell: your terminal's scrollback, selection, and copy work like SSH.

Resume

Run onyx user@host again to resume a detached session (kept 12 hours, in memory). --new starts fresh.

Fallback

Onyx prefers QUIC and falls back to SSH when needed.

Exact output replay

The server keeps a replay buffer per session. Reconnect and you get precisely the bytes you missed, once, in order. After a very long gap, the screen repaints cleanly instead.

Native scrollback

No tmux, no status bar, no copy-mode. Scroll, select and copy exactly like a local terminal, in the terminal you already use.

Ports forward themselves

Start a dev server and it's on your localhost within seconds. Stop it and the forward closes. No -L flags to remember.

New · Agent Guard

Agents use your keys. They never see them.

Run Claude Code, Codex or Gemini on your server with --secret. The agent only gets a look-alike placeholder. Onyx puts the real key back on the way out, and only for that key's own hosts.

  • Real keys stay in onyx-server memory, never on disk
  • Swapped into request headers only, so they can't be posted anywhere
  • Every other destination is blocked and shown in the job log
  • Locked by Linux Landlock: no root, no way around the proxy
